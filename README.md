# Note Widget

Widget Android per note personali, completamente locale e offline.

## Caratteristiche

- Note salvate solo sul telefono.
- Nessun account, server, cloud o calendario esterno.
- Widget ridimensionabile.
- Aggiunta, modifica ed eliminazione delle note.
- Ordinamento per data.
- Evidenziazione configurabile delle note di oggi.
- Formati data in italiano.
- Impostazioni locali per carattere, dimensione, colori e sfondo.
- Nessun permesso Internet richiesto.

## Requisiti

- Android Studio recente.
- JDK 17.
- Android SDK 35.

## GitHub

Il repository può essere usato per conservare il codice. Le note non vengono mai salvate su GitHub.

La GitHub Action presente in `.github/workflows/build.yml` compila una versione debug dell'APK.
